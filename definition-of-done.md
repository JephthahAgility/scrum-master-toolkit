Definition of Done

Purpose

The Definition of Done (DoD) is a shared agreement that describes the quality standards an Increment must meet before it can be considered complete.

Example Definition of Done

A Product Backlog Item is considered Done when:

- Acceptance criteria have been met.
- Development work has been completed.
- Code has been reviewed.
- Required testing has been completed.
- Identified defects have been addressed or appropriately documented.
- Documentation has been updated where required.
- The Product Owner has accepted the work.
- The item meets the team's agreed quality standards.
- The item is in the agreed Done/Accepted status in Jira.

Why the Definition of Done Matters

A clear Definition of Done helps create:

- Transparency
- Consistent quality
- Shared expectations
- Better collaboration
- More reliable delivery

Team Review

The Definition of Done should be reviewed periodically and updated when the team's needs, quality standards, or delivery process change.
